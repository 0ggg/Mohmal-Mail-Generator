## Arabic Guide / الدليل العربي

### 1. المتطلبات
- Python 3.8+
- تثبيت الحزم المطلوبة:
`
pip install -r requirements.txt
`

### 2. طريقة التشغيل
1. تثبيت الحزم المطلوبة:
   `
   pip install -r requirements.txt
   `
2. تشغيل الأداة:
   `
   python main.py
   `
   - سيتم توليد إيميل عشوائي وعرضه
   - سيتم فحص الرسائل تلقائيا كل 3 ثواني
